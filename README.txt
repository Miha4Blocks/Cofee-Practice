ЗЕРНО — УЧЕБНОЕ ПРИЛОЖЕНИЕ КОФЕЙНИ

ЗАПУСК
1. Распакуйте архив целиком.
2. Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.
3. Откройте терминал в папке проекта и выполните:
   python server.py
   Если в Windows команда python не работает, попробуйте: py server.py
4. Откройте в браузере http://localhost:8000
5. Не закрывайте терминал во время работы сайта. Остановка: Ctrl+C.

Просто открывать zerno.html двойным кликом теперь недостаточно:
регистрация, заказы и база данных работают через сервер.
При первом запуске рядом появится zerno.db. Это база данных.
Чтобы сохранить пользователей, каталог и заказы, не удаляйте этот файл.
После перезапуска сервера нужно войти заново.
Корзина и расположение стикеров сохраняются в текущем браузере.
Старые демонстрационные данные из localStorage прежней версии не переносятся.

СОСТАВ ПРОЕКТА И АРХИТЕКТУРА
zerno.html — страница и подключение файлов.
zerno.css — внешний вид, адаптация и печать.
script.js — страницы каталога, корзины, блога, входа, админки и статистики.
server.py — HTTP-сервер, обработка запросов и SQL-запросы.
zerno.db — база, создаётся автоматически при первом запуске.
Документы задания и титульного листа оставлены без изменений.

Браузер отправляет запросы /api/... серверу. Сервер проверяет данные и права,
читает или изменяет SQLite и возвращает ответ в JSON. Библиотеки и сборщик
для JavaScript не используются. База и исходник сервера не выдаются посетителям.

ПРЕДМЕТНАЯ ОБЛАСТЬ И БАЗА
Покупатель выбирает напитки и десерты, добавляет их в корзину, входит в аккаунт
и оформляет заказ. Администратор управляет ассортиментом и блогом, следит
за количеством заказов, выручкой, средним чеком и продажами по категориям.
Таблицы: users (пользователи), products (товары), posts (блог), orders (заказы).
В orders записываются email покупателя, дата, состав, итог и выбранные стикеры.
Состав заказа сохраняется в JSON со снимком названия, категории и цены товара.
Чек здесь является учебным подтверждением заказа.

ПРОВЕРКИ
Пройдены запросы к работающему серверу на временной SQLite:
регистрация, повторные email и логины, неверные данные, вход по логину/email, вход/выход, права администратора,
создание/изменение/удаление товаров и блога, оформление заказа, пустая корзина,
неверное количество и стикеры, расчёт цены сервером, изоляция заказов пользователей,
сохранение категории удалённого товара и запрет скачивания базы/кода сервера.
Пройдены проверки JavaScript в Node: синтаксис, шаблоны страниц и обработчиков,
поиск, фильтр категорий с кавычками, корзина, экранирование текста, ограничение
доступа, 7 столбцов графика, обработчики перемещения стикера.
Внешний вид, мышь/сенсор и окно печати в настоящем браузере не проверялись.
